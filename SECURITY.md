# Security Policy

## Current Development Status

FutureClick is currently in early foundational engineering (`Sprint FC-001`). At this stage, the repository contains architectural contracts, schemas, and workspace tooling. Consequence prediction models, accessibility hooks, and network ingestion services are not yet operational.

## Reporting a Vulnerability

Security and privacy are foundational pillars of FutureClick. We take all vulnerability reports seriously.

Because FutureClick is currently in early private research and development, a formal dedicated security email contact and public PGP key will be published prior to public release.

In the interim, if you discover a security vulnerability or potential privacy issue in this repository:
1. Please do **not** open a public issue on GitHub.
2. Report the vulnerability privately to the project repository owners via GitHub Private Vulnerability Reporting or direct repository maintainer contact.
3. Include a detailed description of the vulnerability, reproduction steps, affected packages, and potential impact.

Maintainers will review the submission promptly, assess severity, and implement appropriate remediations.
